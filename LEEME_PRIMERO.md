# Zombie-nvenidos v0.66 — correcciones online

Actualización de la beta cooperativa para Android/iPhone/PC.

Cambios: las animaciones de armas no se reflejan en otros jugadores; al entrar a una sala nueva los inventarios comienzan vacíos (salvo objetos recogidos después); pasajeros pueden subir a un auto que ya tiene conductor aunque no tengan llave; sirenas de patrullas se transmiten con el estado del vehículo; al morir se abandona la sala; botón Recoger todo, tanto solo como online.

Servidor: npm install && npm start; desplegar el contenido de esta carpeta en GitHub/Render. La partida se cierra si el anfitrión muere o abandona. Los guardados de partidas previas no se cargan automáticamente en salas nuevas, aunque los archivos locales previos permanecen almacenados.

Advertencia: sigue siendo una beta. Es necesario probar dos o más dispositivos reales para validar consistencia, desconexiones y latencia.
